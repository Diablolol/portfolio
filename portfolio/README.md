# Portfolio

โครงสร้างโปรเจกต์ Portfolio แบบโมดูลที่แยกส่วนไฟล์ตามฟีเจอร์ และใช้แกนกลางซ้ำได้ในหลายโปรเจกต์

## โครงสร้าง

- `src/core/` — โค้ดแกนกลางที่ใช้ซ้ำได้
- `src/features/` — ส่วนฟีเจอร์แยกตามโมดูล
- `src/layouts/` — เลย์เอาต์หลัก
- `src/pages/` — หน้า SEO และ entry pages
- `src/styles/` — สไตล์หลักของโปรเจกต์
- `public/` — ภาพและไอคอน

## การใช้งาน

1. เปิด `src/pages/index.html` ในเบราว์เซอร์
2. หรือใช้ `npm start` หากมีเครื่องมือช่วย
